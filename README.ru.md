# HyperVoice

**Голосовой поиск и диктовка для ТВ на HyperOS.**

Зажмите кнопку микрофона на пульте и говорите: текст попадёт в строку поиска или в любое поле ввода любого
приложения. Для телевизоров, в прошивке которых нет работающего голосового помощника. Без root.

## Зачем

Телевизоры Xiaomi с голосовым пультом отвечают на него голосовым помощником, который работает только на
китайском, а у тех, кто чистит прошивку (или живёт не в Китае), его нет вовсе. У приложений своей помощи тоже
нет: кнопка микрофона в поиске приложения, в клавиатуре, в любом приложении для ТВ обращается к
распознавателю речи Android, а на ТВ без сервисов Google рабочего нет. В итоге у пульта есть микрофон, а
слушать его некому.

HyperVoice его слушает.

## Что умеет

- **В приложениях.** Это системный распознаватель речи вместо Google. Кнопка микрофона самого приложения
  просит у него текст, а он отдаёт то, что Whisper услышал с пульта, пока кнопка зажата.
- **Диктовка.** Зажмите кнопку микрофона на пульте, скажите, отпустите: текст напечатается в поле, где стоит
  фокус, в любом приложении, на месте курсора.
- **Поля в фокусе нет?** Он нажмёт за вас кнопку микрофона самого приложения (найдёт её по идентификатору
  доступности или подписи), и приложение само разберётся с текстом, например поиск.
- **И кнопки микрофона нет?** По желанию (переключатель в приложении) он нажмёт кнопку «Поиск», дождётся, пока
  поле поиска получит фокус, и напечатает туда сказанное.
- **И кнопки микрофона нет?** По желанию (переключатель в приложении) он нажмёт кнопку «Поиск», дождётся, пока
  поле поиска получит фокус, и напечатает туда сказанное. Обе опции — ползунки на экране приложения.
- **Несколько языков в одной фразе.** Whisper заранее знает, какие языки ждать (по умолчанию английский и язык
  ТВ, в приложении можно выбрать), поэтому «включи клип Imagine Dragons» получается именно так.
- **Настройка прямо на ТВ.** Экран приложения показывает, всё ли на месте, с кнопкой «Починить» для того, что оно
  может поправить само, и QR-кодом: он открывает на телефоне страницу, куда вводится ключ Whisper.
- **Обновления.** Приложение проверяет релизы на GitHub и предлагает поставить новый (вы подтверждаете). Некоторые прошивки ТВ (Xiaomi) показывают своё предупреждение, что файл не проверен их магазином; выберите «продолжить».
- 20 языков интерфейса, как в [HyperMissions](https://github.com/goodwind/HyperMissions).
- Небольшая плашка на экране показывает, что происходит: *Слушаю…*, *Распознаю…* или что пошло не так.

## Установка

Скачайте `HyperVoice-0.1.1.apk` из [последнего релиза](https://github.com/goodwind/HyperVoice/releases/latest)
(сверьте его SHA-256 со страницей релиза) и установите по сети:

```bash
adb connect <ip-тв>:5555
adb install HyperVoice-0.1.1.apk
adb shell pm grant io.github.goodwind.hypervoice android.permission.RECORD_AUDIO
# Один раз, чтобы кнопка «Починить» в приложении могла вернуть две настройки ниже, если они слетят:
adb shell pm grant io.github.goodwind.hypervoice android.permission.WRITE_SECURE_SETTINGS

# Сделать его распознавателем и включить службу доступности рядом с уже включёнными:
adb shell settings put secure voice_recognition_service io.github.goodwind.hypervoice/.HyperVoiceRecognitionService
adb shell settings get secure enabled_accessibility_services
adb shell settings put secure enabled_accessibility_services "<то, что вывела строка выше>:io.github.goodwind.hypervoice/.HyperVoiceAccessibilityService"
```

Затем задайте ключ Whisper (ниже) и откройте **HyperVoice** в списке приложений ТВ: там видно состояние и
выбираются языки.

Чтобы вернуть как было, верните две настройки к прежним значениям.

### Ключ

Речь превращает в текст Whisper на [Groq](https://groq.com). Нужен ключ, он бесплатен для личного
использования в пределах лимитов Groq: войдите на <https://console.groq.com>, откройте **API Keys** и создайте.
Потом откройте **HyperVoice**: на его экране QR-код. Отсканируйте его телефоном (в той же домашней сети),
вставьте ключ на открывшейся странице, и он проверится в Groq и сохранится. Без телефона, один раз через `adb`:

```bash
adb shell am start -n io.github.goodwind.hypervoice/.SettingsActivity --es groq_key gsk_...
```

Не публикуйте ключ.

### Приватность

Звук пишется только пока идёт распознавание, то есть пока вы держите кнопку на пульте, и отправляется в Groq для
превращения в текст. Больше ничего с ТВ не уходит, аналитики нет, запись не сохраняется. Пока открыт экран
приложения, оно ещё отдаёт страницу ввода ключа в вашей домашней сети (обычный HTTP, по адресу, созданному на
этот визит и показанному только в QR-коде), поэтому ключ идёт по сети без шифрования; закрытие экрана это
останавливает. См. [SECURITY](SECURITY.md).

## Как это работает

Bluetooth-служба Xiaomi принимает голос с пульта и, как только что-то начинает запись с «проводной гарнитуры»,
которую Android показывает для пульта, отдаёт его аудиодрайверу. Поэтому обычный `AudioRecord` с этим
устройством получает микрофон пульта, но только пока кнопка зажата. Сама кнопка приходит в Android как
неназначенная клавиша (код 63), которую не обрабатывает ни одно приложение; обрабатывает служба доступности.
Штатный путь (`com.xiaomi.voicecontrol`) как раз отключают скрипты очистки, а HyperVoice он не нужен.

Подробнее в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Чего он не умеет

- **Работать без интернета.** Нужны сеть и ключ Groq. Офлайн-модель пробовали, она заметно менее точна;
  в проект не вошла.
- **Работать с любым пультом.** Он опирается на то, как голосовой пульт и Bluetooth-служба Xiaomi представляют
  микрофон. Другие ТВ и пульты не проверялись.
- **Включиться сам в первый раз.** Служба доступности и распознаватель включаются через `adb`, как выше:
  Android не даёт приложению сделать ни то, ни другое самостоятельно. После разовой выдачи
  `WRITE_SECURE_SETTINGS` кнопка «Починить» вернёт их, если они слетят.
- **Нажимать кнопку микрофона, которую приложение не подписало.** Он ищет идентификатор доступности кнопки
  Leanback (`lb_search_bar_speech_orb`) и несколько слов в её описании.

## Проверено на

- Xiaomi MiTV-MFTR0 (Android 11) с Bluetooth-пультом: диктовка в поле и кнопка микрофона в поиске приложения.

Отчёты с других ТВ приветствуются.

## Сборка

JDK 17 и Android SDK (платформа 36):

```bash
./gradlew testDebugUnitTest assembleDebug
```

APK окажется в `app/build/outputs/apk/debug/`. Сборку можно сделать с ключом для себя: положите его в
`~/.cache/hypervoice/groq.key` до сборки, и он вшивается в APK (в репозиторий никогда). Такой APK никому не
передавайте. Релизная сборка (`./gradlew assembleRelease`) подписывается ключом из `local/signing.properties`
(вне репозитория) и ключа не содержит.
